## // ABOUT US

SAK大学公認のゲーム開発サークル。私たちは**少数精鋭のアウトプット駆動型エンジニアリング・ユニット**であり、いわゆる「ゆるい部活」ではない。

メンバーはゲーム開発、情報セキュリティ、AI、組み込みシステムに取り組む。目的は明確だ——**大会、論文、そして出荷されるプロジェクト**。私たちは誇大広告よりも検証を、会議よりも実行を重んじる。

> **"Build. Break. Document. Repeat."**

リポジトリ一覧: [github.com/SAK-Game-Development-Department](https://github.com/SAK-Game-Development-Department)

## // CHARTER

<details>
<summary><strong>1. メンバーシップと入会手順</strong></summary>

- **対象・目的:** サークルの目的に共感し、所定の手続きを行った方がメンバーとなります。興味のある分野への参加や掛け持ちは自由です。
- **入会の流れ:**
  1. 代表または分野リーダーへ「志望理由」および「これまでの活動・実績」を伝えてください。
  2. 入会後、最初の **1週間** はお試し期間となります。
- **退会:** 退会を希望する場合は、事前に代表へご相談ください。

</details>

<details>
<summary><strong>2. 活動基準と休会制度</strong></summary>

- **月次参加義務:** **1ヶ月に1回**、何らかの活動（大会・勉強会・イベント等）に参加し、活動報告書を提出してください（結果は問いません）。
- **休会対応:** 正当な理由なく **2ヶ月連続** で活動参加がない場合、一時的に「休会」扱いとなり、共有リソースの利用権限を停止します。
- **復帰について:** 休会状態から復帰したい場合は、簡単な再確認を経ていつでも活動に戻ることができます。
- 長期間活動が見られない場合や、協力姿勢が見られない場合は、相談の上で除名となることがあります。

</details>

<details>
<summary><strong>3. 共有リソースの利用ルール</strong></summary>

- **個人利用の徹底:** サークル経由で利用可能な外部サービス・リソースは、**自身の学習・研究目的のみ**に使用してください。
- **第三者提供・再配布の禁止:** 理由を問わず、アカウントや資料を他人に教える・貸す・譲渡する行為は厳禁です（サービス側の規約違反によりサークル全体への提供が停止する恐れがあります）。
- **自作リソースの保護:** メンバー同士で共有されたリソースについても、制作者の許可なく第三者へ共有・譲渡しないでください。

</details>

<details>
<summary><strong>4. 禁止事項と違反時の対応</strong></summary>

1. 大会参加や論文執筆における不正行為（ズル・盗用等）。
2. 共有リソースの不正利用および外部への提供・流出。
3. メンバーに対するあらゆるハラスメント行為。
4. その他、サークルの雰囲気や運営を著しく害する行為。

**違反時の対応ステップ（役員協議・本人弁明を経た段階的対応）:**

1. 口頭・DMによる注意。
2. 一定期間の活動・共有リソース利用停止。
3. 強制退会。

経緯は役員間で記録し、次回役員交代時へ引き継ぎます。

</details>

<details>
<summary><strong>5. 名義利用・実績の公開について</strong></summary>

- **サークル名の使用:** サークル名義を外部イベント等で使用する場合は、あらかじめ用途と目的を代表および幹部へ連絡し、承認を得てください。
- **名簿の非公開:** メンバー名簿は外部へ公開しません。勧誘は原則として既存メンバーからの紹介・希望者・スカウトのみで行います。
- **実績の公表:** 大会成績・論文・発表などの実績は、個人名またはサークル名にて外部へ公表・PRすることを推奨・許可します。

</details>

<details>
<summary><strong>6. 運営体制・総会</strong></summary>

- **役職:** 代表（1名）、副代表（1名）、開発責任者 / CTO（1名）。各分野のリーダーは有志の取りまとめ役として配置します。
- **定期総会:** 1学期に **2回**（3ヶ月に1回程度）、全メンバー参加の総会を開催します。活動報告・収支報告・役員選任・ルール改正などを行います。
- **ルール改正:** 総会出席者の過半数の賛成をもって本ルールの変更・改定を行います。

</details>
