## // ABOUT US

SAK University's official game development circle. We operate as a **small, output-driven engineering unit** — not a casual club.

Members work across game development, information security, AI, and embedded systems. The objective is concrete: **competitions, publications, and shipped projects**. We value verification over hype, and execution over meetings.

> **"Build. Break. Document. Repeat."**

Repository index: [github.com/SAK-Game-Development-Department](https://github.com/SAK-Game-Development-Department)
